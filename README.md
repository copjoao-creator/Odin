# Odin Focus

Site da Odin Focus (https://www.odinfocus.com.br).

A página principal (`index.html`) abre a **loja** automaticamente, em `loja/`.
Instalação, configuração e uso da loja: [loja/INSTALACAO.md](loja/INSTALACAO.md).

| Pasta / arquivo | Conteúdo |
|---|---|
| `index.html` | Redireciona para a loja |
| `loja/` | Loja virtual (PHP + MySQL, pagamentos pelo Mercado Pago) |
| `img/` | Logotipos da marca |
