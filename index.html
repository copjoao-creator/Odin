      Conexão com o Instagram

      O token fica salvo só neste navegador (localStorage) e é enviado apenas para a API da Meta. No login do Facebook, informe o ID numérico da conta profissional do Instagram. Consulte o README.md para obter o token.

      Monitoramento

      A API tem limite de chamadas por hora. Com 12 publicações, um intervalo de 300 s (5 min) é seguro. No modo demonstração, a atualização acontece a cada 10 s.
